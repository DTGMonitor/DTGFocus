SensiMap quick guide

  1. Load terrain — drop a .dtm, .dxf, .str, .xyz, .csv or ESRI .asc. Point files get gridded; DXF 3DFACE / polyface meshes and Surpac DTM+STR triangulations are rasterised. No file? Press Load demo open pit.
  2. Place the sensor — type coordinates or use Pick position on model. Antenna height is added to the terrain level when snapping.
  3. Choose the movement vector — steepest / horizontal / vertical, or a custom trend & plunge for a known failure mechanism.
  4. Compute — sensitivity = |cos θ| between the radar line of sight and the assumed movement vector; 1 = fully measurable, 0 = invisible to the radar.
  5. Plan — add several sensor positions and read the ranking table to find the best site (lowest in the pit usually wins, as long as it is not in the way).

Remember: the sensitivity map is a starting point — it does not know the real failure mechanism.
